💬 Real-Time Chat Application

A cyberpunk-inspired, terminal-style real-time chat application built using React.js and Vite during my internship at CodTech IT Solutions. This project focuses on performance, clean state management, and an immersive futuristic UI.

🚀 Features

⚡ Real-Time Messaging – Instant message updates without page reloads

🤖 Automated Bot Responses – Simulated AI replies for every user message

📜 Smart Auto-Scroll – Always keeps the latest message in view

🎨 Cyberpunk Terminal UI – Neon glow effects, monospace fonts, and animations

🚀 Fast & Lightweight – Powered by Vite for quick builds and loading

🛠️ Tech Stack

Frontend: React.js

Build Tool: Vite

Styling: CSS3 (Flexbox, Animations, CSS Variables)

🧠 Project Concept

Unlike traditional chat apps, this project simulates a Neural Link-style interaction between a human and an AI system using a terminal-based interface, focusing on UX, responsiveness, and clean component architecture.
